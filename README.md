# Cara E-commerce Website

A responsive, multi-page fashion storefront built with HTML, CSS, and vanilla JavaScript. This educational project includes product browsing, a single-product view, a persistent shopping cart, a blog, and company/contact pages.

## Features

- Responsive layouts for desktop, tablet, and mobile
- Product catalogue and product-detail page
- Shopping cart stored in the browser with `localStorage`
- Quantity updates, item removal, and a sample `SAVE10` coupon
- Contact and newsletter form interactions
- Accessible navigation labels and descriptive image text

## Built with

- HTML5
- CSS3
- Vanilla JavaScript
- Browser `localStorage`

## Run locally

No build step is required. Clone the repository and open `index.html` in a browser, or serve the folder with a local static server such as VS Code Live Server.

```bash
git clone https://github.com/SaabaMire/E-commerce-websites.git
cd E-commerce-websites
```
